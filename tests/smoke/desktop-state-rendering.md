# Desktop State Rendering Smoke Checklist

- [ ] Basic replay shows only the green bulb active for idle state.
- [ ] Basic replay shows only the red bulb active within 2 seconds for working state.
- [ ] Confirmation replay shows only the yellow bulb active for waiting state.
- [ ] Stale-source replay shows unavailable patterning without showing green, red, or yellow as active.
- [ ] No adjacent visible status text, counters, or install button are shown beside the lamp.
- [ ] `Install Hooks` is available from the app tray menu.
- [ ] The indicator remains readable at compact desktop size and on high-DPI displays.
